## Interdisciplinary Competency:

### AI/ML at Oak Ridge

As an AI/ML Research Intern at the University of Tennessee-Oak Ridge Innovation Institute (May 2024 to August 2024), I worked on a problem that sat directly between physics and machine learning: identifying superconducting pairing symmetries from quasiparticle interference (QPI) spectra.

I designed and implemented a convolutional neural network in Python using PyTorch, then evaluated performance on s-wave versus chiral d-wave superconductors. The model reached 97% to 100% classification accuracy, which was exciting not just because of the number, but because it showed we could make the workflow more reliable for researchers interpreting complex patterns.

I also built an automated analysis component using Grad-CAM so researchers could see where the model was focusing, including subtle features that are easy to miss through standard observational inspection alone.

## Research Competency

### DataPeer and My Thesis

My thesis work, DataPeer, grew out of one question: how do we make LLM-based exploratory data analysis actually usable for both experts and non-experts?

DataPeer is a web application that combines:

- Open-ended high-agency interaction (OHA), where users can ask freeform questions
- Structured low-agency interaction (SLA), where users get guided workflows

The system uses a React frontend and FastAPI backend, with an LLM integrated into both qualitative and quantitative analysis flows for uploaded CSV datasets. Instead of treating the model like an oracle, the design treats it like an instrument that needs constraints and observability.

In the quantitative pipeline, the model proposes code, runs it in a sandbox, and surfaces outputs alongside explanations. That "generate -> run -> explain" loop is intentional. It makes results more inspectable, and it turns each run into something closer to a reproducible experiment: prompt (hypothesis), generated code (method), execution trace (experiment), and captured output (result).

What matters to me most is that uncertainty is not hidden. If code fails, if schema assumptions break, or if outputs are brittle, the system shows that explicitly. That transparency is the point. Scientific and analytical tools should help us think better, not just answer faster.

### Undergraduate Research Assistant (UTC)

From September 2023 to August 2024, I worked as an Undergraduate Research Assistant at the University of Tennessee at Chattanooga. I used Python with PyBaMM and LiionPack to model circuit configurations and battery aging behavior, including state of charge (SOC), state of health (SOH), and degradation trends under different operating conditions.

I also did literature review on multi-agent reinforcement learning and graph neural networks for reconfigurable battery systems, with the goal of improving energy efficiency while minimizing long-term battery degradation.

This was my first exposure to research, and I learned a lot about both the hardware side of energy systems and what the research role actually demands: patience, iteration, and clear communication. It was also my first direct entry point into Grand Challenges competencies, especially Energy and Sustainability.

## Social Consciousness: Hackathons for Real Community Problems

Another part of Grand Challenges that changed me was learning how to apply engineering in spaces that are directly community-facing. Hackathons became one of those spaces for me, not just for building quickly, but for building toward social impact.

At EmoryHacks, my team earned runner-up in the Education Track with **FieldReady**, an AI-powered EMT training app. We built patient simulation, response-area map quizzes, flashcards, and radio protocol practice using React, Express, Gemini, ElevenLabs, and Leaflet.

This project made me more community-focused: listen to what people go through, then turn that into tools that are clear, practical, and trustworthy.
